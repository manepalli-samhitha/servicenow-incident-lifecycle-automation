## Project Overview
This project demonstrates an end-to-end Incident Management lifecycle in ServiceNow for the scenario **“Unable to connect to Corporate VPN from home office.”**

## Objective
Document and validate incident creation, classification, knowledge integration, escalation, Level 2 investigation, change-related handling, resolution, knowledge creation, SLA validation, and final validation.

## Workflow
Service Creation → Service Offering → Incident Creation → Classification → Agent Assist → Knowledge Integration → Reassignment → Level 2 Investigation → Configuration Item Update → On Hold / Awaiting Change → Child Incident → Cause → Resolution → Knowledge Creation → SLA & Related Records Validation → Final Validation

## Stakeholders
- End Users
- Service Desk Agents
- Level 2 Support / Network / Hardware Teams
- Change Management Team
- ServiceNow Administrator

## Technology / ServiceNow Modules
ServiceNow ITSM, Incident Management, Service Catalog / Service Offering, Agent Assist, Knowledge Management, Change Management, CMDB, SLA / Task SLAs, Service Operations Workspace, Related Records and Child Incidents.
